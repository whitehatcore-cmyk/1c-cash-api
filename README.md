# Учёт наличных денежных средств в кассах

Конфигурация 1С:Предприятие 8.3 для многокассового учёта наличных
с HTTP API для интеграции с внешними системами.

## Что реализовано

- Справочник `Кассы`, документы `ПоступлениеНаличных` и `ВыдачаНаличных`
- Регистр накопления `ДенежныеСредстваВКассах`
- Отчет по остаткам денег в кассах
- HTTP-сервис `CashAPI`: `GET /v1/balances`, `POST /v1/operations`
- Идемпотентность операций через регистр `ОбработанныеОперацииAPI`
